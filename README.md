# 关系的银河原型

基于 Three.js 的人物关系网站。当前版直接转录 XMind content.json：72 位人物、1 个星形主题、85 条关系、8 个独立网络（含 2 个孤点）。一个无标题且没有关系的空占位节点不展示。

默认进入远望、持续旋转的银河模式，侧栏默认收起。只有旋转按钮改变自动旋转开关；望远镜始终执行“回到银河远望并打开关系星云介绍”，不保持按下状态。支持地图模式、时间轴、人物聚焦、完整注释、搜索与领域筛选。

所有节点基础大小相同，只有聚焦核心节点放大。银河连线为柔和银色细丝，指向端以圆润突触末梢代替箭头，双向保留双侧末梢、无向不加末梢。远望时姓名淡显，每隔约 5–6 秒随机巡游一条关系：单向从尾端向突触末梢流动，两端姓名依次点亮；双向和无向关系整体与两端同步点亮。聚焦、悬停、拖动、页面后台及系统减少动态效果偏好下暂停巡游，不改变用户的旋转开关。缩放采用有界弹簧，旋转有缓动惯性。

一度／二度／全部仅在地图或银河聚焦时显示。关系聚焦默认突出两端，一度只看两端，二度扩展到两端邻居，全部恢复全网；切换不会改写关系原文。所有人物卡统一在侧栏打开，肖像下不展示署名文字；来源与完整授权保留在工具栏 © 入口中。银河不显示重置键；地图和时间轴重置清除分类与选择并关闭侧栏，分别恢复布局、滚动到时间轴顶部。

图上关系短标签全部为中文，原始英文与其他注释仍原样保存在人物卡及文字对照中。随机巡游仅点亮连线、两端节点与姓名，不显示关系文字；主动聚焦时才显示关系标签。银河引导淡显，进入网站 30 秒后关闭，不因重新全览而重现。

二阶控制论的 4 条未注释连接，图上统一显示「主题关联」，完整源文保持为空。地图关系标签避让实际可见的人名、节点、控件及其他标签，缩放和拖动时重新定位。银河聚焦关系文字正常随连线显示，不额外限制在两个人名中央或自动隐藏；侧栏可阅读完整内容。

地图关闭人物卡时退出放大、退回全图，保留该人物及一度关系的高亮，无关节点从聚焦时的低亮度（0.14）回升至中亮度（0.48）。这一状态不保留放大节点或深度栏；再次聚焦、切换模式、筛选或重置后清除。初始与重置状态为高亮度（1）。银河关闭卡片仍保留聚焦，不受地图行为影响。

银河巡游中，人名、节点自发光与光晕共享同一亮度包络，不改变节点大小。星云外围新增程序化金色细粒流带（桌面 2600、移动端 1200 粒），仅作氛围，不是新增关系、不拦截点击；聚焦时减弱，切到其他模式或页面后台时停止更新，系统偏好减少动态效果时静止。

## 运行

### 本轮交互与性能调整

- 地图全览（含关闭侧栏后的余光状态）固定单个节点位置，仍可整体平移、缩放与点击聚焦；聚焦后的局部拖动保持不变。
- 菜单在「全部」后优先显示「神经科学」。只改变导航顺序，不重排领域的银河位置。
- 银河聚焦复用固定线条缓冲区，只更新移动端点关联的线条；去除每 64ms 重建全部几何的计算尖峰和跳帧。光鞘、银色突触、巡游方向、金色粒子与自动旋转保留。隐藏地图和时间轴不随银河聚焦重复更新。
- 同机后台基准测试（85 条连线及光鞘，热身 10 次后采样 30 次；不含屏幕渲染）：更新中位数约从 14.53ms 降至 2.57ms。结果随设备变化，不等同于真实浏览器帧率。
- 右下角新增「留言 · 私信」。邮箱私信已接入 `neuroplus@126.com`，通过访客自己的邮件应用发送。公开留言需站主授权 Cloudflare 后台后启用；未接通时明确显示尚未开放，不伪造留言或只保存到个人浏览器。详见 [留言后台说明](guestbook/README.md)。

## 主要文件

- `src/xmind-source.json`：规范化的原始节点、关系、端点与继承合并后的箭头；原文不可静默改写。
- `src/xmind-enrichment.js`：规范姓名、缺失年代、简短介绍及补充资料来源。
- `src/taxonomy.js`：10 个主要领域与全部人物的流派、专业及跨域标签。主分类用于导航，不代表唯一身份。
- `src/relation-tour.js`：随机关系巡游调度、方向与姓名亮起时序、线条光效。
- `src/nebula-motion.js`：帧率无关、有距离边界的惯性缩放弹簧。
- `src/soundtrack.js`、`public/audio/`：已署名录音、自动播放降级、手动开关及状态同步。
- `src/map-layout.js`：独立网络的确定性排布、留白与节点碰撞修正。
- `src/data.js`：旧人物展示资料与新 XMind 数据的合并、关系短标签和分类。关系 ID 与 XMind 保持一致。
- `src/xmind-portraits.json`、`src/portraits.js`：72 位人物头像的来源、许可及未核实授权声明。
- `public/xmind-map.md`：可阅读、核对的全部节点与关系原文，由 `pnpm export:xmind` 生成。
- `src/main.js`：3D 场景、交互、搜索和人物卡逻辑。
- `src/styles.css`：桌面与移动端界面样式。
- `public/assets/freud-map-preview.webp`：本轮关系校正所依据的新版原始图谱预览。

## 扩充数据

修改源图后更新 `src/xmind-source.json`，按稳定的 XMind ID 核对，不用数组位置猜测关系。新增人物需要在 enrichment 中补展示资料。所有 `detached` 节点都是自由主题，不能按父子存储关系连接到弗洛伊德。没有关系文字的边保持空原文，界面明确注明未注释。

图上 `label` 是网站短标签；`fullText` 必须逐字等于源关系标题。卡片展示原端点次序，避免“前者／后者”在反向箭头中产生歧义。关系记录忠实转录不等同于逐条史实考证。

银河按出生年的排名设置椭球半径（含公元前年份），领域决定角向聚类；聚焦时一度邻居等距分散。主题没有出生年，不伪造年代。

验证：`pnpm check` 检查源文、方向、端点、孤点、分量、领域、布局、统一大小、关系巡游时序以及后台模拟交互；`pnpm build` 构建。自动检查不使用屏幕或鼠标权限，不替代真实设备上的视觉验收。

额外验证：`npm run check:geometry` 检查动态线条缓冲区复用、等弧长、法线、边界和点击；`npm run check:guestbook` 在隔离 SQLite 中验证公开留言后台；`node scripts/validate-dynamic-tube.mjs --benchmark` 可复跑新旧线条的后台性能对比。
